PDF Extractor, direto no navegador

A mesma ideia do app para Mac: escolha vários PDFs, clique em executar e receba um único arquivo de texto com o conteúdo de todos, separado por arquivo e sem os cabeçalhos e rodapés repetidos.

Os PDFs são lidos no seu navegador. Nenhum arquivo é enviado para lugar nenhum.

O app original é em Python, com pdfplumber e Tkinter, e o GitHub Actions gera o aplicativo para Mac sozinho. Esta página refaz a mesma lógica em JavaScript com o PDF.js: as mesmas regras de limpeza, o mesmo formato de relatório e o mesmo resumo no final.
